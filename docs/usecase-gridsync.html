Use Case Diagram — Smart Solar Microgrid Trading System

All actor interactions derived from the SE4040 requirement specification

UML symbols

🧍 Stick figure = Actor
⬭ Ellipse = Use Case
▭ Dashed system box = System boundary
— Solid line = Association (actor interacts with use case)
- - ► «include» = mandatory sub-behaviour
- - ► «extend» = optional / conditional behaviour

1. Actors

Actor Type Access channels Responsibility
Backoffice Officer Primary Web application only System administration, staff users, prosumer activation/reactivation, microgrid nodes, reservations assistance
Grid Operator Primary Web + Mobile Station/slot operations, monitor bookings, scan QR, finalize energy transfer, view map/dashboard
Solar Prosumer Primary Mobile application only Register (NIC), profile, book/update/cancel slots, QR, history, search, dashboard, nearby nodes
Google Maps API Supporting (external system) Mobile Provides map tiles / location display for nearby grid nodes
